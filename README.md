# Beyond These Walls

Responsive, buildless website for Keisha’s developing San Francisco mission.

## Preview

Open index.html, or run `python3 -m http.server 8000` from this directory. No install or build is needed.

## GitHub Pages

Upload these files at the root of a separate repository named beyond-these-walls. In Settings → Pages, choose Deploy from a branch, main, / (root). Do not copy CNAME files from another project.

## Before accepting inquiries or donations

Set the confirmed contactEmail and donationUrl in config.js. The contact form prepares an email in the visitor’s email app; it does not automatically submit, store requests, or provide a support inbox. Until configured, submission stays disabled. Only HTTPS donation links are enabled.

No church qualification, tax exemption, tax deductibility, active shelter, housing placement, program statistics, testimonials, or affiliations are claimed. Founder content is limited to the supplied overview; no private personal history is published. Confirm mission wording with Keisha before launch.

## Images
