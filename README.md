# Beyond Walls New Paths

Buildless GitHub Pages website for Keisha Garrett’s developing San Francisco Bay Area mission for women experiencing homelessness. The proposed legal name is subject to California availability and Keisha’s final approval.

## Preview and hosting
Open index.html or serve this directory with a static HTTP server. The existing GitHub Pages repository path remains beyond-these-walls; no domain migration or build configuration change is needed.

## Current public status
Mobile showers, hygiene supplies, outreach, resource navigation, and food/new clothing support are proposed. Direct services have not launched. Housing and a fixed site remain future possibilities. No incorporation, IRS recognition, operating schedule, partnership, results or tax deductibility is asserted. Anyone may browse the independent resource directory.

The contact form opens a draft in the visitor’s email app and sends/stores nothing itself. The direct email address remains available without JavaScript. Never use this as confidential intake or emergency response.

## Donation controls
Payments are disabled in config.js. Before enabling giving, approve legal/tax disclosures, charity compliance, organization-owned receiving arrangements and financial controls; update all planning-status copy. A valid HTTPS donationUrl and donationsApproved=true are required for the optional link behavior. No credentials belong in client-side configuration.

## Images and privacy
Existing purple, black and gold branding and the existing digitally edited founder portrait are retained. Stock images are illustrative; credits and license links appear on photo-credits.html. Fonts use browser fallbacks, without a Google Fonts request. No analytics, ad trackers or server-side contact intake are added.
